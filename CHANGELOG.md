# Changelog / 更新日志

## v0.2.8

- Fixed popover alignment when starting an exercise from the right-click menu.
- Improved menu bar anchoring while the exercise countdown is visible.
- Made "Do not remind me again today" reversible and added a sleeping response while paused.
- Restored neutral toast button styling and synchronized the installation guide used by the package.

- 修复从右键菜单开始运动时弹窗错位的问题。
- 优化运动倒计时显示期间的菜单栏弹窗锚点。
- “今天不再提醒”现在可以取消，暂停提醒时小花会进入睡眠状态。
- 恢复 toast 按钮的中性样式，并同步安装包内的安装失败说明。

## v0.2.7

- Added configurable Kegel reminder interval: 30, 45 recommended, 60, and 90 minutes.
- Added reminder schedule modes, today-only pause, easter egg toggle, and restart action.
- Improved daily check-in slot calculation so it follows the selected reminder interval.
- Updated install failure guide for modern macOS versions.

- 增加提肛提醒间隔设置：30、45（推荐）、60、90 分钟。
- 增加提醒时段、今天不再提醒、彩蛋开关和重启插件。
- 今日打卡点会跟随提醒间隔动态变化。
- 更新新版 macOS 安装失败解决文档。

## v0.2.6

- Added pet-style menu bar interactions, sleep state, feeding and drinking toasts.
- Added daily check-in and status view.
- Added settings, launch-at-login, popup reminder toggle, and GitHub update checking.
- Refined DMG installer artwork and macOS packaging.

- 增加菜单栏宠物互动、睡眠状态、投喂和喝水提醒。
- 增加每日打卡和状态页。
- 增加设置、开机启动、弹窗提醒开关和 GitHub 检查更新。
- 优化 DMG 安装界面和 macOS 打包流程。
