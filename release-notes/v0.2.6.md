# v0.2.6 / 版本 0.2.6

## 中文

这是提肛小花的公开发布版本，包含菜单栏提醒、提肛节奏引导、宠物互动、状态页、每日打卡和新版 DMG 安装界面。

如果 macOS 提示无法验证，请右键 App 选择“打开”。如果仍无法打开，可运行：

```sh
xattr -cr /Applications/提肛小助手.app
```

## English

This public release includes menu bar reminders, guided Kegel sessions, pet interactions, status view, daily check-in, and the redesigned DMG installer.

If macOS blocks the app, right-click it and choose “Open”. If it still cannot open, run:

```sh
xattr -cr /Applications/提肛小助手.app
```
